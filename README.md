# 🧘 Meditation Website

A calming and responsive meditation website designed to promote mindfulness, relaxation, and mental well-being. This project provides a peaceful digital space where users can explore meditation practices and develop healthy mindfulness habits.

## ✨ Features

- Clean and modern user interface
- Responsive design for different screen sizes
- Peaceful and visually appealing layout
- Smooth navigation between sections
- Interactive elements using JavaScript
- User-friendly experience

## 🛠️ Technologies Used

- **HTML5** – For website structure
- **CSS3** – For styling and responsive design
- **JavaScript** – For interactive functionality
